# Запись ресурсов VPS

Заполните этот шаблон во время будущего integration gate для VPS примерно с
1 vCPU, 2 GB RAM и 20 GB локального диска.

| Показатель | Наблюдение |
| --- | --- |
| RAM | не проверено |
| Свободный диск | не проверено |
| Throughput | не проверено |
| Swap | не проверено |
| Непроверенные ограничения провайдера | не проверено |

Foundation передаётся changes 2–5 как минимальная NixOS-конфигурация. VM и
live-проверки пока не выполнены.
